# DriverGuard AI – Driver Distraction Detection

A deep learning-powered Driver Monitoring System (DMS) using EfficientNet-B0 to classify 10 driver distraction behaviors in real-time.

## Features
- 📷 Upload image or use live camera feed
- 🎯 High-accuracy EfficientNet-B0 backbone
- 📊 Confidence score with top 3 predictions
- 🔍 Aspect-preserving preprocessing for accurate results
